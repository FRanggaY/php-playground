# Prerequisites

Before learning Object-Oriented Programming, you should have a basic understanding of PHP.

You should be comfortable with:

- Variables and data types
- Operators
- if / else
- Loops
- Arrays
- Functions
- Basic error handling
- Running PHP scripts

You should also know how to run a simple PHP file:

```bash
php example.php
```

If these topics are unfamiliar, learn the PHP basics first.
