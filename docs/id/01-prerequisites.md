# Prasyarat

Sebelum mempelajari Pemrograman Berorientasi Objek, Anda harus memiliki pemahaman dasar tentang PHP.

Anda harus sudah terbiasa dengan:

- Variabel dan tipe data (Variables and data types)
- Operator (Operators)
- if / else
- Perulangan (Loops)
- Array
- Fungsi (Functions)
- Penanganan error dasar (Basic error handling)
- Menjalankan skrip PHP (Running PHP scripts)

Anda juga harus tahu cara menjalankan file PHP sederhana:

```bash
php example.php
```
Jika topik-topik ini belum familiar, pelajari dasar-dasar PHP terlebih dahulu.
