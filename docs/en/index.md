# Introduction

Welcome to the *PHP Object-Oriented Programming (OOP)* course.

This course covers OOP concepts in PHP.

## What You Will Learn
- Classes and objects
- Properties and methods
- Constructors
- Visibility and encapsulation
- Inheritance
- Polymorphism
- Abstraction

## Goal

By the end of this course, you should be able to understand and build PHP applications using Object-Oriented Programming.
